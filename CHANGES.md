# Changes

## v0.1.0

First release, beta. For Moodle 5.2 and 5.3.

- Annotate any Moodle page with pen, highlighter, text, box, ellipse and eraser
  tools, from a button that also closes scribbles, or a footer help link.
- Select annotations after drawing them to move, resize, rotate, recolour or
  delete them. Undo covers all of it.
- Save annotations as annotation pages, and open them again to carry on editing.
- Download a screenshot, or save it to "My scribbles". Screenshots need HTTPS.
- Delete saved pages and screenshots. Each user may keep 100 of each by default;
  administrators can change this.
